How to Write YouTube Video Descriptions That Rank

Descriptions are not a dumping ground for links. Structure them so skimmers get the point in two lines - and search systems understand the video.

Why YouTube descriptions still matter

Most viewers never expand the description. Search and accessibility still do. A clear description helps YouTube understand the topic, supports chapters, and gives returning fans links and context.

Recommended structure

  1. First 2–3 lines - what the video is and who it is for (visible before “Show more”).
  2. Chapters - timestamped sections for longer videos.
  3. Resources - tools, downloads, related videos.
  4. Soft CTA - subscribe, next watch, newsletter.
  5. Hashtags - 2–5 relevant tags at the end.

Copy-paste template

In this video, [audience] will learn [outcome] using [method/tool].

0:00 Intro
0:45 [Section]

- [Resource]
- Related video: [URL]

SEO tips that are not spam

  • Use the primary phrase naturally in the opening lines - once is enough.
  • Write for humans first; keyword walls get ignored.
  • Match the title’s promise - do not bait-and-switch in the body.
  • Add captions/subtitles separately; description is not a transcript dump unless you intentionally publish one.

Frequently asked questions

How long should a YouTube description be?

Helpful length: strong opening lines, then chapters and links. Avoid empty or stuffed descriptions.

Do hashtags belong in descriptions?

A few relevant ones at the end can help. Dozens of unrelated tags do not.

Should every video have chapters?

Yes for multi-section videos longer than a few minutes - they help viewers and search.
